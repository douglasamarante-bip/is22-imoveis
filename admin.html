IMPORTADOR POR CÓDIGO

Trazer imóvel de outra base

Digite o código do anúncio. O sistema busca os dados, mostra uma prévia e baixa as fotos para a IS22 após sua confirmação.

FONTE
Bonanza ImóveisBusca pública por código
ImportanteO importador funciona quando o site é aberto pelo servidor (`INICIAR_IS22.bat`, `npm start` ou Railway). Abrir o HTML diretamente pelo Explorador do Windows não permite buscar a origem.

Como funciona

  1. Digite o código e clique em Buscar anúncio.
  2. Confira e, se precisar, edite título, preço, localização e descrição.
  3. Confirme que você tem autorização para reutilizar o material.
  4. O servidor baixa as fotos e publica o imóvel no catálogo da IS22.

O plugin não remove marca-d’água, não acessa área restrita e não tenta contornar bloqueios do site de origem.
